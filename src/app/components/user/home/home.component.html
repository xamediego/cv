Experience

Sogeti

Software Engineer

During my graduation internship at Sogeti, I designed and implemented a modern containerized architecture leveraging Java WebAssembly (TeaVM) and Spinkube. I built a microservice-based registration platform using Kotlin for the backend and TeaVM/HTML/CSS for the frontend, deploying it with Helm on Kubernetes (EKS). The project demonstrated the feasibility of Java-based SPA architectures using TeaVM and WASI runtimes, overcoming limitations such as missing reflection and JS interop. I also implemented a custom SPA router, Shadow DOM-based component system, and dynamic JSON parsing logic.

Java • WebAssembly • TeaVM • Kubernetes • Spinkube • Kotlin • OAuth • Shadow DOM
